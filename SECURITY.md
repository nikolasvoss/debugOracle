# Security Policy

## Supported Versions

DebugOracle is currently a public alpha. Security fixes are provided only for
the latest `0.2.x` release.

| Version | Supported |
| --- | --- |
| `0.2.x` | Yes |
| `< 0.2` | No |

## Reporting a Vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/nikolasvoss/debugoracle/security/advisories/new).
This is the project's only security-reporting channel. Please do not disclose a
suspected vulnerability in a public issue, discussion, or pull request.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Remove secrets, credentials, private debug captures, and proprietary
target data before attaching evidence.

The maintainers will acknowledge the report through the private advisory,
investigate it, and coordinate remediation and disclosure there. Response and
resolution times depend on the report's severity and the availability of this
volunteer-maintained alpha project.
