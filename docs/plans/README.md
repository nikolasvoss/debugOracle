# Active Plan Index

This directory contains active plans, approved implementation material, and
future proposals. Completed and closed delivery records are pruned; the current
source of truth is the [roadmap](../../ROADMAP.md) for priorities, the
[workflow rules](../workflows/AGENT_WORKFLOW_RULES.md) for delivery process,
and the relevant module [specification](../specs/README.md) for behavior.

## Future Proposals

- [Testing Plan Phase 4](TESTING_PLAN_PHASE_4.md) and
  [Testing Plan Phase 5](TESTING_PLAN_PHASE_5.md) are future, non-binding
  proposals. They become implementation scope only when scheduled through the
  roadmap and a task spec.

## Plan Convention

Every new plan starts with a purpose and one status: `Active` or `Proposal`.
When delivery closes, migrate durable behavior to specifications, guides, or
the roadmap, then remove the completed record. Keep scratch notes out of
versioned docs; promote actionable items to the roadmap or a task spec.
